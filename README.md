# ResultsService

Веб-приложение для загрузки CSV-файлов, их валидации и обработки, расчёта интегральных показателей и сохранения результатов в PostgreSQL.

Проект состоит из серверной части на ASP.NET Core 8 и клиентской части на Angular. ASP.NET Core API и PostgreSQL запускаются в Docker-контейнерах, Angular запускается локально через Angular CLI.

# Описание проекта

ResultsService предназначен для обработки CSV-файлов, содержащих результаты выполнения операций.

После загрузки файла приложение:
1. принимает CSV-файл через Angular;
2. передаёт файл в ASP.NET Core Web API;
3. проверяет структуру CSV;
4. проверяет корректность значений;
5. преобразует строки CSV в объекты приложения;
6. рассчитывает интегральные показатели;
7. сохраняет исходные значения в PostgreSQL;
8. сохраняет рассчитанный результат в PostgreSQL;
9. возвращает результат обработки Angular-клиенту;
10. отображает рассчитанные показатели пользователю.

Также приложение позволяет получать сохранённые результаты с использованием фильтров и получать последние 10 значений для выбранного файла.

# Функциональность

Приложение реализует следующие основные операции.

##1. Импорт CSV-файла

Пользователь выбирает CSV-файл в Angular-приложении и отправляет его на сервер.

API:
    -принимает файл;
    -читает содержимое;
    -проверяет структуру;
    -проверяет значения;
    -рассчитывает показатели;
    -сохраняет данные в БД;
    -возвращает результат обработки.

##2. Получение результатов

API позволяет получить список рассчитанных результатов из таблицы Results.

Поддерживаются фильтры:
    -имя файла;
    -начальная дата от;
    -начальная дата до;
    -среднее значение от;
    -среднее значение до;
    -среднее время выполнения от;
    -среднее время выполнения до.

##3. Получение последних значений

Для выбранного файла API возвращает последние 10 записей.

Записи сортируются по полю Date в порядке убывания.

# Предварительные требования

Перед запуском проекта необходимо установить:
    -.NET 8 SDK;
    -Node.js;
    -npm;
    -Angular CLI либо возможность запуска через npx;
    -Docker Desktop;
    -Git — если проект используется из Git-репозитория.

PostgreSQL отдельно устанавливать не требуется.

PostgreSQL запускается автоматически в Docker-контейнере.

# Запуск проекта
##Шаг 1. Перейти в корень проекта
##Шаг 2. Запустить API и PostgreSQL
    docker compose up --build
##Шаг 3. Проверить API
    http://localhost:8080/swagger
##Шаг 4. Запустить Angular
    Перейти в каталог клиента:
        cd ResultsService.Client
    При первом запуске установить зависимости:
        npm install
    После установки запустить Angular:
        ng serve
    Если Angular CLI не установлен глобально:
        npx ng serve

После запуска Angular-приложение доступно по адресу:
    http://localhost:4200
